# Customer Sales Analysis Project

## About Project

This project analyzes customer sales data using Python and Pandas.

The project helps understand sales, profit, quantity sold, product performance, and city-wise sales.

## Tools Used

* Python
* Pandas
* Matplotlib

## Analysis Performed

* Total Sales
* Total Profit
* Total Quantity Sold
* Average Sales
* Highest Sales
* Highest Selling Product
* Product-wise Sales
* City-wise Sales
* Profit Margin
* Sales Charts

## Visualizations

* City-wise Sales Chart
* Product-wise Sales Chart

## Dataset

The dataset contains information about:

* Customer
* City
* Product
* Quantity
* Sales
* Profit
